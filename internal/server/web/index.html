Mosso

    Workspaces and chats are kept in memory only. They are lost when Mosso stops or a sandbox is terminated or expires; branches and pull requests stay on GitHub.

    Welcome to Mosso

    A workspace is a GitHub repository checked out on a new mosso/* branch in a Vercel Sandbox, with Claude Code ready to work on it.

    What should Claude work on?

    Claude Code runs in the sandbox, in the repository checkout. Describe a task; follow-ups continue the same conversation. When you are happy, publish the changes as a pull request.

    Claude is working…

    New workspace

    Mosso provisions a sandbox (30 minutes), clones the base branch onto a new working branch and installs Claude Code. This takes about a minute.

    Create pull request

    Mosso commits the sandbox's changes and pushes the branch to GitHub from this machine; the sandbox never gets your GitHub token. A rebased branch is pushed with --force-with-lease.

    Connect GitHub

    1. Open GitHub to create a token ↗. Mosso's permissions are preselected: Contents and Pull requests: Read and write, with a 90-day expiration.
    2. Under Repository access, choose the repositories Mosso may work on, then click Generate token.
    3. Copy the token and paste it here.
